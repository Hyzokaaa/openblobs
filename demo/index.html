    Bring your own design

    Draw the parts, keep the guarantees: same seed, same avatar, contrast-checked colours. The monsters are 15 SVG snippets and one call.

    import { layeredDesign, openblob } from "openblobs";

const monsters = layeredDesign({
  name: "monsters",
  layers: [
    ["", hornsSvg, earsSvg],           // "" = sometimes none
    [roundSvg, squareSvg, ghostSvg],   // fill="{body}"
    [twoEyesSvg, oneEyeSvg, sleepySvg],
    [smileSvg, fangsSvg, ohSvg],
  ],
});

openblob(user.id, { design: monsters });

    Use it

    Plain SVG strings, a data URI helper and a React component.

    npm install openblobs

import { openblob, openblobUri } from "openblobs";
const svg = openblob(user.id, { size: 32 });

import { Openblob } from "openblobs/react";
<Openblob seed={user.id} size={32} title={user.name} />
